Software: tipos e o papel do sistema operacional

Daqui em diante tiramos o foco das peças e mergulhamos nos programas que dão vida a elas.

🎯 Objetivos de aprendizagem

  • Classificar software em sistema, aplicativo e utilitário.
  • Explicar as funções essenciais de um sistema operacional (SO).
  • Entender o que são drivers, firmware/BIOS e aplicativos.
  • Conhecer o conceito de software livre, código aberto e licenças.

6.1 Os três grandes grupos de software

GrupoO que éExemplos
Software de sistemaFaz o hardware funcionar e serve de base para os outros programasWindows, Linux, macOS, Android, iOS, drivers, BIOS/UEFI
Software aplicativoResolve tarefas do usuárioNavegador, WhatsApp, Word, Excel, jogos, Photoshop
Software utilitárioFerramentas de apoio e manutençãoAntivírus, descompactador (WinRAR/7-Zip), limpador de disco, gerenciador de backups

6.2 O sistema operacional (SO): o gerente de tudo

O sistema operacional é o programa mais importante do computador. Sem ele, o hardware não serve para nada. Ele é o primeiro software carregado ao ligar e fica rodando o tempo todo, fazendo quatro trabalhos principais:

  1. Gerenciar o hardware — decide quem usa o processador, quanta RAM cada programa recebe, o que é gravado no disco.
  2. Oferecer uma interface — janelas, ícones, menus e toques para você não precisar falar "a língua da máquina".
  3. Executar e organizar aplicativos — abrir, alternar e fechar programas com segurança.
  4. Cuidar de arquivos e permissões — guardar arquivos em pastas e controlar quem pode acessar o quê (Módulo 8).
🧠 Analogia final da cozinha

O SO é o gerente do restaurante: escala os cozinheiros (CPU), organiza as bancadas (RAM), controla a despensa (disco), atende os pedidos na ordem certa e impede que um cozinheiro atrapalhe o outro. Os aplicativos são os cozinheiros especialistas: cada um faz um prato (tarefa).

Multitarefa: a mágica de "tudo ao mesmo tempo"

Você ouve música, navega e digita "ao mesmo tempo". Na verdade, a CPU alterna entre as tarefas milhões de vezes por segundo, dando a ilusão de simultaneidade. Quem decide essa fila é o sistema operacional.

6.3 Drivers: os tradutores

Cada peça (impressora, placa de vídeo, webcam) fala uma "língua" própria. O driver é o software que traduz as ordens do sistema operacional para a língua do dispositivo. Sem driver, a peça não funciona ou funciona mal.

💡 Situação clássica

"Comprei uma impressora e ela não imprime!" → na maioria das vezes, falta instalar o driver (baixado no site do fabricante) ou conectar o cabo/rede. Suporte técnico resolve muito isso.

6.4 BIOS/UEFI: o software que acorda o hardware

Ao apertar o botão de ligar, antes do Windows aparecer, um pequeno programa gravado em um chip da placa-mãe entra em ação: a BIOS (antiga) ou UEFI (moderna). Ela confere se as peças estão OK (o POST) e entrega o comando para o sistema operacional no disco.

6.5 Licenças: grátis, pago, livre

ModeloComo funcionaExemplos
Proprietário (comercial)Você paga/licencia e não pode ver nem alterar o códigoWindows, macOS, Microsoft Office, Photoshop
FreewareGratuito, mas de código fechadoNavegadores Chrome/Firefox*, VLC, WhatsApp
Código aberto (open source)O código-fonte é público: qualquer um pode ver, usar e modificarLinux, Firefox, VLC, LibreOffice
Software livreCódigo aberto + liberdade garantida de usar, estudar, modificar e compartilharLinux (distribuições), GIMP
Assinatura (SaaS)Pagamento mensal/anual, geralmente na nuvemMicrosoft 365, Netflix, Canva Pro, Google Workspace

* O Chrome é gratuito mas de código fechado; o Firefox e o Chromium (sua base aberta) são de código aberto.

⚠️ Pirataria

Software "crackeado" é ilegal e é uma das maiores portas de entrada para vírus e roubo de dados. Hoje há alternativa gratuita de qualidade para quase tudo: LibreOffice (Word/Excel), GIMP (Photoshop), Linux (Windows).

6.6 32 bits vs 64 bits (rápido)

É a "largura" com que o sistema trabalha. 64 bits é o padrão atual e permite usar mais de 4 GB de RAM. Sistemas de 32 bits são antigos e limitados — se vir essa informação ao baixar um programa, escolha sempre a versão 64 bits em computadores modernos.

ℹ️ Resumindo

Software se divide em sistema (SO, drivers, BIOS), aplicativo (tarefas do usuário) e utilitário (manutenção). O SO gerencia hardware, arquivos, programas e a interface. Drivers traduzem o SO para os dispositivos. UEFI/BIOS inicia tudo. Licenças variam de pagas a abertas e gratuitas.

🛠️ Atividade prática

  1. Descubra qual sistema operacional e versão você usa: Windows → Configurações → Sistema → Sobre (veja "Edição" e "Tipo de sistema: 64 bits").
  2. Liste 3 aplicativos, 2 utilitários e 1 software de sistema instalados no seu dispositivo.
  3. Baixe e instale um software livre: sugerimos o LibreOffice (libreoffice.org) ou o navegador Firefox. Perceba: é grátis, legal e completo.
