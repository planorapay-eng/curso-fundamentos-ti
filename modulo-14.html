Módulo 14 · 3 horas

Como nascem os programas: lógica, algoritmos e primeira programação

Você já sabe o que é software. Agora descubra como ele é criado — e escreva seus primeiros algoritmos.

🎯 Objetivos de aprendizagem

  • Explicar o que é um algoritmo com exemplos do cotidiano.
  • Entender as três estruturas da lógica: sequência, decisão e repetição.
  • Ler um pseudocódigo simples e prever o resultado.
  • Conhecer as principais linguagens de programação e para que servem.
  • Escrever seu primeiro programa visual no Scratch.

14.1 Algoritmo: a receita de bolo

Algoritmo é uma sequência finita e ordenada de passos que resolve um problema. Você usa algoritmos o dia todo sem saber:

🧠 Algoritmo "trocar uma lâmpada"

1) Pegar a escada. 2) Pegar a lâmpada nova. 3) Subir na escada. 4) Girar a lâmpada queimada até soltar. 5) Colocar a nova. 6) Testar o interruptor. 7) Se não acender → verificar disjuntor e voltar ao passo 6. Pronto: sequência + decisão. Um programa de computador é isso, escrito em uma linguagem que a máquina entende.

O computador é rápido, mas burro: ele faz exatamente o que o algoritmo manda — nem mais, nem menos. Por isso programar é, antes de tudo, pensar com clareza.

Todo programa do mundo — WhatsApp, jogos, sistema do banco — é construído combinando essas três peças. Sério.

Exemplo para ler com calma

Problema: somar todos os números de 1 a 5.

total ← 0
PARA n DE 1 ATÉ 5 FAÇA
  total ← total + n
FIMPARA
escreva(total)

Executando na cabeça ("teste de mesa"): total=0 → +1=1 → +2=3 → +3=6 → +4=10 → +5=15. O programa imprime 15. Esse exercício de simular passo a passo é o treino nº 1 de lógica.

E como o computador entende texto se ele só entende 0 e 1 (Módulo 1)? Um programa chamado compilador/interpretador traduz o código-fonte (o texto que o programador escreve) para código de máquina (os 0s e 1s que a CPU executa — Módulo 3).

14.4 Quem faz o quê no desenvolvimento

  • Front-end: a parte visual com que o usuário interage (HTML, CSS, JavaScript).
  • Back-end: os bastidores: servidor, regras de negócio, banco de dados (Python, Java, C#, Node...).
  • Full-stack: faz os dois.
  • Mobile: apps de celular (Kotlin/Android, Swift/iOS, Flutter/React Native para os dois).
  • Dados/IA: análise, machine learning (Python + SQL dominam).
  • QA/Testes: garante a qualidade antes de lançar.

14.5 Ferramentas para começar hoje (grátis)

  • Scratch (scratch.mit.edu) — programação visual de blocos, perfeita para internalizar lógica brincando.
  • Portugol Studio — pseudocódigo em português (o "Visualg" moderno).
  • Python — instale python.org e use o IDLE, ou rode direto no navegador em replit.com.
  • VS Code (code.visualstudio.com) — o editor de código mais usado do mundo, gratuito.
ℹ️ Resumindo

Algoritmo = passos ordenados para resolver um problema. Toda programação se apoia em sequência, decisão (SE) e repetição (PARA/ENQUANTO). Linguagens são ferramentas para públicos diferentes — Python é a porta de entrada clássica. Compiladores traduzem código em 0s e 1s. Comece pelo Scratch, sem medo.

🛠️ Atividade prática

  1. No papel: escreva o algoritmo de "fazer um café com leite" (ou outro do seu dia a dia) com passos numerados, incluindo pelo menos um SE e um ENQUANTO. Ex.: "ENQUANTO xícara não estiver cheia, despeje café".
  2. Teste de mesa: qual a saída deste pseudocódigo?
    x ← 2
    ENQUANTO x < 20 FAÇA
      escreva(x)
      x ← x * 2
    FIMENQUANTO
    (Resposta: 2, 4, 8, 16 — confira simulando passo a passo!)
  3. Scratch: acesse scratch.mit.edu, crie uma conta e faça o gatinho andar e falar "Olá, mundo!" usando 3 blocos. Depois tente fazê-lo repetir a fala 5 vezes.
