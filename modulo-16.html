💡 O caminho mais comum no Brasil

Help Desk/ Suporte N1 → Suporte N2/Analista → especialização (redes, cloud, segurança ou dados). O suporte ensina a resolver problemas reais e é a porta de entrada mais acessível para quem está começando sem faculdade. Desenvolvimento é o caminho mais concorrido, porém com mais vagas remotas.

16.2 Certificações que abrem portas (nível inicial)

  • CompTIA A+ — o clássico mundial de suporte técnico (hardware + software + troubleshooting).
  • CompTIA Network+ / Cisco CCNA — redes.
  • CompTIA Security+ — segurança.
  • AWS Certified Cloud Practitioner / Microsoft AZ-900 (Azure Fundamentals) — nuvem, nível introdutório, ótimas para primeiro emprego.
  • ITIL Foundation — gestão de serviços de TI (muito pedida em suporte corporativo).

Nenhuma é obrigatória para começar, mas todas pesam no currículo. A AZ-900 e a Cloud Practitioner são consideradas as mais acessíveis para iniciantes.

16.3 Estudando de graça (ou quase)

  • Fundação Bradesco (Escola Virtual) — cursos gratuitos com certificado, em português.
  • CS50 (Harvard, edX) — a melhor introdução à ciência da computação do mundo, gratuita (em inglês, com legendas).
  • freeCodeCamp — programação web completa, gratuita, com projetos.
  • Curso em Vídeo (Gustavo Guanabara) — hardware, redes, Python e mais, em português, no YouTube.
  • Microsoft Learn / AWS Skill Builder — trilhas oficiais gratuitas de nuvem.
  • Kaggle — dados e IA na prática.

📖 Glossário completo do curso

Backup
Cópia de segurança dos seus dados (regra 3-2-1).
BIOS/UEFI
Firmware que inicia o computador antes do sistema operacional.
Bit / Byte
Menor unidade de informação (0 ou 1) / conjunto de 8 bits.
CPU
Processador — executa as instruções dos programas.
DNS
Traduz nomes de sites em endereços IP.
Driver
Software que traduz o sistema operacional para um dispositivo.
Firewall
Filtro que controla o que entra e sai da rede.
GPU
Processador de vídeo — gera as imagens da tela.
HD / SSD
Armazenamento mecânico (lento) / eletrônico (rápido).
Hypervisor
Programa que cria e gerencia máquinas virtuais.
IP
Endereço numérico que identifica um dispositivo na rede.
IaaS / PaaS / SaaS
Nuvem: infraestrutura / plataforma / software como serviço.
Malware
Qualquer programa malicioso (vírus, ransomware, spyware).
Nobreak (UPS)
Bateria externa que mantém equipamentos ligados na queda de energia.
Phishing
Golpe que "pesca" dados com mensagens/sites falsos.
RAM
Memória de trabalho, rápida e volátil.
Roteador
Distribui a internet e direciona os dados na rede local.
SO (Sistema Operacional)
Software que gerencia hardware, arquivos e programas.
VM (Máquina Virtual)
Computador simulado por software dentro de outro.
2FA
Autenticação em duas etapas — senha + segundo fator.
